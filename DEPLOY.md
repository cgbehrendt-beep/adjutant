# ADJUTANT v4.0 · Deployment auf GitHub Pages

## Dateien
```
adjutant-github/
├── index.html      ← die App
├── manifest.json   ← macht sie installierbar
├── sw.js           ← Offline-Fähigkeit
├── icon.svg        ← App-Icon
└── DEPLOY.md       ← diese Anleitung
```

## Schritte

### 1. GitHub-Account
github.com → Sign up → Email eingeben → kostenlosen Account erstellen

### 2. Neues Repository anlegen
github.com/new → Name: `adjutant` → Public → "Create repository"

### 3. Dateien hochladen
"uploading an existing file" anklicken →
alle 4 Dateien (index.html, manifest.json, sw.js, icon.svg) hineinziehen →
"Commit changes"

### 4. GitHub Pages aktivieren
Repository → Settings → Pages →
Source: "Deploy from a branch" →
Branch: main / Folder: / (root) →
Save

### 5. App-Adresse
Nach 1-2 Minuten erscheint die Adresse:
https://IHR-USERNAME.github.io/adjutant/

### 6. Auf Fold 7 installieren
Chrome → Adresse eingeben → Menü (⋮) → "App installieren"

### 7. Erinnerungen einrichten
In der App: Tab QUELLEN → Anleitung dort befolgen
(3 Google Kalender Einträge, täglich wiederkehrend)
